# Clean Wash & Co

**Projet Client - Clean Wash & Co**
Ce projet est un site web vitrine développé sur-mesure pour un client.
🌐 [Visiter le site en production : https://cleanwashandco.fr/](https://cleanwashandco.fr/)

## Description
Clean Wash & Co est un site web vitrine premium pour une entreprise spécialisée dans le nettoyage automobile et le nettoyage à domicile de mobilier (canapés, matelas, tapis) en Île-de-France. Le site met en valeur les prestations premium, affiche les tarifs de manière transparente, présente une galerie de réalisations et propose plusieurs points de contact (téléphone, WhatsApp, réseaux sociaux).

## Stack Technique
- **HTML5** : Structure de la page et sémantique SEO.
- **CSS3 (Vanilla)** : Stylisation sur-mesure, variables CSS, animations fluides (keyframes), design responsif.
- **JavaScript (Vanilla)** : Logique d'interface (menus mobiles, scroll dynamique, filtres, animations d'éléments au scroll).

## Prérequis d'installation
- Un navigateur web moderne (Chrome, Firefox, Safari, Edge).
- Aucun serveur backend n'est requis car il s'agit d'un site web statique.

## Installation et Lancement
Pour lancer le projet en local, suivez ces étapes simples :

1. Clonez ce dépôt.
2. Naviguez dans le dossier du projet (`site_clean_wash_and_co`).
3. Ouvrez simplement le fichier `index.html` dans votre navigateur web.

## Arborescence du Projet
```
site_clean_wash_and_co/
```
