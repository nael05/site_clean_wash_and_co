# Clean Wash & Co

**Client Project - Clean Wash & Co**
This project is a custom-built showcase website developed for a client.
🌐 [Visit the production site: https://cleanwashandco.fr/](https://cleanwashandco.fr/)

## Description
Clean Wash & Co is a premium showcase website for a company specializing in car detailing and home furniture cleaning (sofas, mattresses, rugs) in the Île-de-France region. The site highlights premium services, transparently displays prices, presents a gallery of completed work, and offers multiple contact methods (phone, WhatsApp, social media).

## Tech Stack
- **HTML5**: Page structure and SEO semantics.
- **CSS3 (Vanilla)**: Custom styling, CSS variables, smooth animations (keyframes), responsive design.
- **JavaScript (Vanilla)**: Interface logic (mobile menus, dynamic scroll, filters, element animations on scroll).

## Installation Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge).
- No backend server is required as it is a static website.

## Installation and Launch
To run the project locally, follow these simple steps:

1. Clone this repository.
2. Navigate to the project folder (`site_clean_wash_and_co`).
3. Simply open the `index.html` file in your web browser.
